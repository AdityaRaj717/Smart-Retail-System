## Tool Installation

# Windows
winget install --interactive --exact dorssel.usbipd-win


# Linux
sudo apt install linux-tools-virtual hwdata



## Forwarding the Camera
usbipd list

from output get the busid 
eg: 2-4 

## Forwad the selected Camera
usbipd attach --wsl --busid 2-4

## Chaning Access in linux (Optional) 
sudo chmod 777 /dev/video0


## Deforwarding the Camera
usbipd detach --busid 2-4
